# Pulse Personal 0.8.1 preview

Pulse 0.8.1 is a public preview for Apple Silicon Macs. It keeps `latest` on
0.7.2 and must be selected explicitly with `@preview`.

This preview removes a confirmed noisy recall path: a weak direct capsule no
longer falls through to the looser archive threshold. In the compact product
benchmark it stayed silent on all five unrelated controls while recalling 12
of 15 useful memories. It also includes the reproducible installed-product
benchmark adapter used for that comparison.

The exact npm archive passed a clean Apple Silicon installation before npm
publication. Live owner-machine use passed in Codex and Claude Code. Cursor
live acceptance and production readiness remain pending.

Install deliberately:

```bash
npx -y @zbs-gg/pulse@0.8.1 init codex
```
