# Pulse Personal 0.8.2 preview

Pulse 0.8.2 is a public preview for Apple Silicon Macs. It keeps `latest` on
0.7.2 and must be selected explicitly with `@preview`.

This preview fixes the cold-search readiness failure found in 0.8.1. A cancelled
or short request no longer kills the local embedding protocol, and Doctor now
makes a real BGE-M3 semantic query. The publication workflow installs the exact
npm archive on a clean Apple Silicon runner and refuses publication unless that
query succeeds.

The release also returns up to four short, distinct memories within the existing
context limit and includes the reproducible full LoCoMo adapters. On the frozen
1,535-question run, Pulse scored 1,230 correct answers (80.13%), compared with
1,231 (80.20%) for equal-model Mem0 and 959 (62.48%) for the previous Pulse
baseline. This is development evidence, not a production-readiness claim.

Owner-machine recall and writing in Codex and Claude Code remain a separate
acceptance step after publication. Cursor and other operating systems are not
part of this preview's live support claim.

Install deliberately:

```bash
npx -y @zbs-gg/pulse@0.8.2 init codex
```
