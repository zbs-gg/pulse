# Pulse Personal 0.8.3 preview

This preview preserves complete meaningful moments and adds OpenCode 1.18.x
support on Apple Silicon macOS. Stable remains 0.7.2.

Runtime and model downloads now come from this GitHub release. No separate
paid storage service is required. The installer permits only the GitHub asset
CDN redirect and still verifies signatures, exact sizes and hashes.

Previously, a memory request containing four items could be refused because
an adapter accepted only three; a blanket no-retry instruction could then
leave an explicitly requested memory unsaved. The native and BB adapters now
accept the full structured set, including coexisting feelings, human feeling
names, causes, and separate user-stated versus inferred provenance.

The local engine validates the complete set before durable admission and
returns a receipt for every part. Long summaries become linked parts. Exact
replay is idempotent, accepted parts recover after restart, and transient
storage failures preserve pending content. `stored` requires successful
receipts for all parts. `pending` and `partial` remain visibly incomplete.
Canonical storage and complete-moment reading do not wait for background
search indexing; each part retains a separate recoverable index receipt.
A validation refusal before admission permits correcting the input in the
current turn. Memory never starts another model turn or blocks Stop.

A recalled moment carries a reference for reading all its eligible parts with
pagination. Corrections, deletion and project boundaries still apply.
Historical feelings remain after their influence on current context fades.
The transport envelope is 16 MiB; oversized input is explicitly refused before
admission, without truncation. Structured summaries are limited to 1 MiB per
input item. Raw transcripts, secrets, computer paths and backend model calls
remain excluded from automatic capture.

Native Codex, Claude Code and Cursor use `pulse_memory`; OpenCode exposes the
same tool through its native plugin. The BB adapter in `integrations/bb` adds
`pulse_moment` alongside its recall and write tools. Existing singular
`emotion` inputs remain compatible with the plural `emotions` input.

Validation includes 4, 21 and 61 parts, mixed feelings, long Russian text,
partial writes, exact replay, database close/reopen, signed project recovery,
current corrections, deletion and cross-project isolation. Tests use isolated
homes and synthetic memories. Build evidence does not establish one-day use
or production readiness. The publication workflow separately installs this
exact archive and requires a real semantic query before publishing npm and
finalizing this matching prerelease.

Install explicitly:

```sh
npx -y @zbs-gg/pulse@0.8.3 init codex
```

Review the displayed file changes and check each connected host with
`pulse doctor <host>` after installation. Old databases upgrade to schema 46;
older readers and writers are refused after that migration. Preserve a vault
backup before upgrading. Intel Mac, Windows and Linux are not public support
claims for this preview.
