# Commercial licensing

Garden Pulse is released under the **GNU Affero General Public License v3.0**
([`LICENSE`](./LICENSE)).

The AGPL is intended for the open-source community. It requires that **anyone
who runs a modified version of Pulse as a network service must release the
complete source of that service** under the AGPL.

If that does not fit your case — for example you want to:

- embed Pulse inside a **proprietary product** without open-sourcing it,
- run a **closed SaaS / hosted offering** built on Pulse,
- integrate the engine into a **company-internal system** you do not intend to publish,

then a **commercial license** is available. It removes the AGPL copyleft
obligations under separate, negotiated terms.

Pulse is owned by a single copyright holder, which makes dual licensing clean
and possible.
